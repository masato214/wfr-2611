| 決まり | 中身 | 決定 |
|---|---|---|
| エラー | エラーは正本（07_qa/test-specs/errors.json）から引き、文言と次の一手をコードに書かない。画面ごとのエラーの出し方 | D-069・D-128.63 |
| 権限 | 役割の束を付け、必要な人だけ個別に足す・外す（誰に × 何に × どの層で × できること） | D-125.120・D-073 |
| 記録（証跡） | 契約中はずっと残す。退会で消す。実行の記録の出し方 | D-125.133・D-125.106 |
| 言語 | 第1フェーズは日本語だけ。画面の文字は言語ごとの辞書から出す | D-128.56 |
| 秘密・外とのつなぎ | 外に出る・保存する・AI を呼ぶ・ファイル・プロセス・通知・決済・秘密は関門 C1〜C8 だけを通す。ゼロトラストの決まり（03_architecture/ゼロトラストの決まり.md） | D-128.113 ほか |
| 日付と時刻 | 時刻は DB で世界標準時の印つき（timestamptz）で持ち、画面では日本時間で出す。期限のように日付だけのものは date（時差でずれない） | D-128.130 |
| お金 | 円は小数を持たない整数として扱う（DB の型は numeric のまま整数を入れる）。消費税は請求書ごと・税率ごとに 1 回だけ端数を処理し、端数は切り捨て | D-128.130・D-125.125 |
| ログ | ログは共通の 1 か所から出す（console を直に使わない）。1 行 1 件の JSON で、どの依頼のログかが分かる ID を付ける。秘密・パスワード・個人の連絡先は出さない | D-128.130 |
| フォルダの切り方 | 機能（流れと操作）ごとにまとめる。API は apps/api/src/features/<流れ>/<操作>/、画面の中身は apps/web/features/<流れ>/<操作>/。共通の部品と関門は packages/* と apps/web/components/k のまま。今のファイルは、その流れのチケットで触るときに移す | D-128.130 |
| 部品の版 | 部品は出てから 21 日を過ぎた版だけ | D-128.124 |
| 分岐の型 | 入力・対象の状態・時間の流れ・入口・利用者の状態・失敗・操作の揺れ・守り の 8 つの観点。書いていない＝漏れ。状態を持つものは「対象の状態 × 入口 × 利用者の状態」の表を書き、どのマスにも結果・受け持ち・テスト | D-128.133 |
| 入力の確かめ方 | 入口で厳しく確かめる（ゼロトラスト）。契約に正式な形を書く（id は format: uuid・本文は strict な形で知らない項目を許さない）。正しくない値は 422 で断り、中で 500 になる道を残さない | D-129.42 |
| 口の契約の検査（fuzz） | 作った口は全部、契約の fuzz（G36）の的に入れる。本物のサーバーが差している hooks と fuzz の的が同じかを scripts/ci/fuzz_targets.py（G47）が突き合わせ、外すのは理由つきの台帳だけ。検査は作った時点で CI に並べる | D-095・K-62 |
| 消したものの扱い | チケットを消したら、そのチケットに付いて残る AI の実行の記録（1 件・一覧）も「見つからない」（404）にし、チケットと一緒に読めなくする。広げて、親を消したら、その親に付いていた記録（承認・やり取り・子の記録など）も全部、画面と口からは 404。記録は証跡として DB に残す | D-129.43・D-136.2 |
| まだ作っていない口 | 契約にあってまだ作っていない口は 501（NOT_IMPLEMENTED）で止める（fail-closed）。素の読み書きでも表がまだ無ければ 501 | D-128.113 |
| DB の関数 | security definer の関数は search_path に pg_temp を入れ、execute は要る役だけに渡す | D-128.171 |
| DB の関数の実行権 | 関数の execute は既定で誰にも渡らない。呼ぶ役には migration で grant する（K-426） | D-128.171 |
| チケットを切る時点 | 決める人に聞くことは切る時点で出し切る。期待結果は起きる結果（状態コード・画面の文・行や段の変化）で書き、別のチケットに回した機能はそれまでの間の振る舞いを書く（着手前のチケットは CI の G64 が K13・K14 で照らす）。先に実装があるチケットは頭に prior_impl（なし か <枝>@<sha>）を書き、精査がコードの分かれ道とチケットの行を突き合わせる | D-129.52・D-129.53 |
| 守りの判定で例外になったとき | 承認できるか・メンバーか・書けるか などの守りの判定が内部の不具合で判定できなかったら、通さず 503（E-PAGE-003）で止める側に倒す。中身を返さず、ログは場所と例外の種類だけ | D-136.1 |
| 別のチケットに回した操作 | そのチケットができるまで画面にボタンを出さず、口を直に呼ばれたら 501（NOT_IMPLEMENTED）で断る。チケットにはそれまでの間の振る舞いを書く | D-136.3・D-128.113 |
| 書き換わった後の確定 | 確定の操作（例：完了にする）を押す間に、元にした内容（例：実施事項）が別の人に書き換わっていたら、確定せず 409（E-CONF-017）で止めて最新を見せる | D-136.4 |
| 戻る先と選ぶものの指し方 | 戻る先（next）は new URL(next, location.origin) で読み、同じ origin のときだけ使う。セッションや人は「最新の 1 つ」「その人の全部」で選ばず、その要求が指すものを直に指す | D-136.5 |
