## 目的

- **見られないページは 404**（在るかを漏らさない）。下書きのページは持ち主だけ・公開済みのページを直している下書きの版は書いている本人だけ

- AI がこの 30 日に開いた数は `reference_logs`（0072）を数える。この表の行の守りは「チケットが見える人だけ」なので、数える DB の関数 `app.kn_page_ai_opened_30d` をこの葉の migration で作る（見えるページの数だけを返す）

- **`getKnowledgePage` の鍵（土台 3.1）**：`id`・`title`・`desc`（列 `summary`・空なら空の文字）・`state`・`must`（列 `is_must`）・`must_blocked`・`place`・`acts`・`body`・`draft`・`request`・`copied_from`・`shared_from`・`raise_to`・`foot` の 15 鍵ちょうど
  - `place`：`{ shelf, shelf_name, group_id, folder_id, folders }`。`app.kn_shelf_kind`・`app.kn_shelf_name`・`app.kn_folder_names(folder_id)`（棚の直下から）。`group_id` はグループの棚だけ scope の id・ほかは null。K-675 の `toPlace` を使う
  - `body`：公開済みのページは最新の公開の版の `{ doc, text }`（そのまま）。まだ 1 度も書き終えていないページ（`state = 'draft'`）は自分の下書きの版の本文
  - `draft`：自分（`author_member_id = 自分`）の生きている下書きの版があれば `{ title, desc, doc, saved_at }`（`title`・`desc` は版でなくページの今の題名・説明＝K-679 の保存はすぐ効くので下書きの欄の初めの値に使う・`saved_at` は版の更新の時刻の ISO 文字）、無ければ null。ほかの人の下書きの版は行の守りで見えないので null。まだ書き終えていないページは `body` と `draft` が同じ下書き
  - `must_blocked`：公開済みで必ず守るが付いていないページの本文（`text`）が 2,000 字（`KNOWLEDGE_MUST_TEXT_MAX`）を超えるとき `"too_long"`、それ以外（2,000 字ちょうど・必ず守るが付いている・下書きのページ）は null。字は `char_length`（コードポイント）で数える（SQL で数える）
  - `copied_from`：`copied_from_page_id` があり、元が自分に見える（`app.kpage_visible`）なら `{ page_id, title, shelf_name, folders, must, gone: false }`（`folders` は元の置き場のフォルダの名前を棚の直下から・直下なら空の並び＝K-693 の帯の字）。**元が消えた・自分に見えない（入っていないグループ・他人の自分の棚）は同じ形で `{ page_id: null, title: "", shelf_name: "", folders: [], must: false, gone: true }`**（在るかを漏らさない）。写しでないページは null
  - `foot`：`{ last_editor_name, last_edited_at, version, ai_opened_30d }`。最後の公開の版の `published_by` の表示名・`published_at`・版の番号（ページの `current_version`）。**まだ書き終えていないページは `last_editor_name` null・`last_edited_at` はページの更新の時刻・`version` 0**。時刻は ISO 8601（UTC・`Z`）の文字。`ai_opened_30d` は DB の関数の答え（下）
- **前の版の 2 本**：公開した版（`kind = 'published'`・消していない）だけ。下書きの版はどの番号でも読めない（書いている本人でも 404）。`listKnowledgeVersions` は新しい順（`version` の大きい順だけで決まる＝書き終えた時刻が同じでも揺れない）・1 行 `{ version, published_at, by_name }`・`{ data: […], meta: { count } }`（`count` は返した行の数）・**200 行で切る**（切ったらログに `[knowledge] 版の一覧を 200 行で切った` を 1 行・題名は出さない）。`getKnowledgePageVersion` は `{ data: { version, published_at, by_name, body } }`・番号は道の `:v`（口の中では `a.c.req.param("v")`・形は契約の `PATH_PATTERNS` が先に確かめる）・版が無ければ 404。一度も書き終えていないページの `versions` は空の一覧・`versions/1` は 404
