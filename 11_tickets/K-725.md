## 前提と制約

- 正の絵の欄は `canvas: [全部の組]`（まとめ役の決め・2026-11-22）：この葉は画面のコードを消すだけで、自分の正の組を持たない。消した後も、ほかの画面の見た目が変わっていないことを全部の組の突き合わせで確かめる（K-350 などと同じ書き方。`canvas_none` は changes に画面のコードがあると使えない）

分類: TOOL

- **この葉が K-712 より先**：K-712 の `depends_on` に K-725 を足す（まとめ役）。順が逆だと、K-712 が旧い道を消した後に `/dev/memory` の頁と 3 つの試験が 404／500 で赤になる
- **消すのは web だけ**：`apps/api`・`packages/*`・`apps/bridge`・`05_flow/*`・`08_api/*` は変えない（K-712・K-711・K-722）。旧い道は動いたまま、呼ぶ所が無くなるだけで、この葉の間は害が無い
- **頁の道を変える訳**：前の頁の下半分（いつも許可・使用量・通知）は記憶ではないが、前から 3 つの前からの試験が開く見本の頁だった。置き場の画面（アカウント・お知らせ・設定）ができるまでの見本で、`RequireSession` の中・本物の API につながる。新しい道 `/dev/ai-settings`、見出し「AI まわりの設定（見本）」（見本の頁の字。製品の画面ではないので仮のまま）。部品の並びは前のまま（`AlwaysAllowList`・`UsagePanel`・`NotifyToggles`）。`max-w-[860px]`（任意値）は台帳に載る生の長さなので、新しい頁では `max-w-3xl`（標準の幅）にする
- **「覚えました」の行は残す**：「覚えて」の印と道具 `remember` は K-712 の決めで今は残る（代表に確認中・勧めで切る）。会話の画面は印を受けた結果の「覚えました：…」を字だけで出す。押しても記憶の画面へ行けない（前から行けなかった）
- 控え帳：この葉は新しい口・断りの番号・文を足さない。**画面に出る文**は見本の頁の見出しだけ（仮）。会話の画面の文は変えない
- `RequireSession` を外した頁は無い（新しい頁も付ける）。ログインしていない人は `/login?next=%2Fdev%2Fai-settings` へ送られる
