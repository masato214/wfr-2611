## 目的

上の棚（会社・グループ・共有された物）の公開済みのページを、自分の棚に**写して**直せるようにする口 1 本を作る（契約は K-675 が宣言済み・今は 501）：`copyKnowledgePage`（POST /api/v1/knowledge_pages/:id/copy・入力 `{ folder_id? }`・201 `KnowledgePageStub`）。入力・答え・断りは土台 2・3.2・4 章。

- **写し**は自分の棚（本人の主のグループ・自分の棚の印・持ち主は本人）の**公開済みのページ**で、本文は元の公開の最新の版をそのまま（版 1）。題名は「<題名>」のまま・1 行の説明もそのまま・**必ず守るの印は写さない**。`copied_from_page_id` に元を残す（どのページの写しかが帯に出る＝K-677 の `copied_from`）。**元は何も変わらない**
- 入れるフォルダは自分の棚のフォルダ（無ければ棚の直下の最後）。**同じページを何度でも写せる**（勧め・代表に確認中なし＝土台の決め）。写しの元が「必ず守る」でも、食い違いの扱い（会社 > グループ > 自分で上のページが効く）は K-697 が決め、帯の「食い違う所は上のページが効きます」の字は画面（K-693）が `copied_from.must` から出す
- 自分の棚のページは写せない（409 E-KNW-080）。書き終えていないページは写せない（409 E-KNW-010）。共有された物は写せる（共有先の人の主のボタンが「写して直す」・K-689）
- **ページを読むと操作に `copy` が出る**（K-677 が置いた `page-parts/act-copy.ts` の中身をこの葉が差し替える）

  5. 元の公開の最新の版の本文（`kind = 'published'`・消していない・版の大きい順の先頭）を `{ doc, text }` のまま読む
  6. **ページを作る**：`state = 'draft'` で入れる（行の守り `knowledge_pages_create` が下書きで作ることを求める）：`scope_id` ＝呼んだ人の主の所属（`members.scope_id`）・`is_personal = true`・`owner_member_id` ＝自分・題名・説明は元のまま・`is_must = false`・`folder_id`・`position` ＝自分の棚の同じフォルダの最後（`nextPagePosition`・無ければ 10）・`copied_from_page_id` ＝元・`current_version = 0`
  7. **版を作る**：下書きの版（`kind = 'draft'`・`version = 1`・本文は 5 のまま・`author_member_id` ＝自分）を入れ、すぐ公開にする（`kind = 'published'`・`published_at = now()`・`published_by` ＝自分）。K-680 の「書き終える」と同じ道（行の守りの `_add`・`_decide` が通る形）

- **同時に写しても壊れない**：写しごとに別のページ・別の版なので錠は要らない（同じページを 2 つの画面が同時に写すと写しが 2 つできる）
- **本文・題名・説明はそのまま**：入口の整え（NFKC・前後の空白）は元の保存済みの文字には掛けない（口が書く文字は DB から読んだ物）。本文は `{ doc, text }` を丸ごと写す（口が `validateDoc` を掛け直さない・元が通った形）
- **DB の失敗の言葉 → 番号**：引き金の `KNW_FOLDER_SHELF`・`KNW_PERSONAL_SCOPE`（口の確かめをすり抜けた競り負け）→404（写せる物が無い扱い）。**それ以外の例外は 503 E-PAGE-003**（何も書かない・ログに例外の種類だけ・題名を出さない）

- **権限の波及**：グループを抜けた・共有をやめられた直後も、次の操作から今の所属で決まる（毎回 DB の関数が決める）。置き場の棚は呼んだ人の**今の**主の所属（入り直しは要らない）
- 外へ出ない：メール・お知らせは出さない・AI も呼ばない・ログに題名・本文を出さない

### 画面が使う答えの形（K-693 の「写して直す」が使う）

- ページを読む（K-677）の `acts` の `"copy"` で「写して直す」ボタンを出す（共有された側の主のボタン）。押す → `{ data: { id, title, desc, state: "published", must: false, place } }`（201）。画面は写し（自分の棚）を開き、「直す」へ進める（直すのは K-683）。入れるフォルダを選ぶ小窓は下絵に無いので、`folder_id` を送らない（棚の直下の最後に入る）か、画面の葉が決める

- 409 E-KNW-080（自分の棚のページは写せない）・010（書き終えていない）は押せない形にして訳を文にする（文面は台帳・仮）
