## 目的

詳細（K-571）が本文を**読む形**で出すとき、編集の部品（Tiptap・ProseMirror）を読み込まずに、文書の木 `doc`（K-561）を画面に描く部品 `DocView` を作る。読む画面は一番よく開くので、編集のための 100kb 超を読み込ませない（`performance.md`）。編集に入ったときだけ K-567 の `DocEditor` が遅く読み込まれることも、この葉の試験で確かめる。

詳細で本文のチェックの箱を読む形のまま付けられるか（K-571・K-447 の決め）は、`DocView` の `onToggleTask` を渡すかどうかで使う側が決める。この葉は取り扱いを渡された／渡されないときの動きだけを持つ。

## 前提と制約

分類: CRUD

- **本文の道具の決め（代表 2026-11-22・D-150.61）への当たり方**：読む形は、K-584 が広げた文書の木の節と印を全部描く（絞らない）。リンクの守り（http・https・mailto だけ）・画像は押せない形（D-150.57）は変えない。編集の道具の数や並びは持たない（K-567・K-587・K-568 の物）

- **この葉の正の絵（下絵に足す状態）**：読む形の本文は下絵 v2 の詳細の状態（f4v2-detail-new・detail-worked・detail-empty）の中に描かれているが、その持ち主は K-571。この葉だけが持つ状態は無い。canvas_field_gate は mock: を空にできないので、本文の読む形（チェックの箱・リンク・表・画像）だけを並べた状態 `f4v2-body-read`（ticket K-577）を下絵 v2 の `mocks.tsx` に足してもらう（PM への頼み・T2 の報告の残り）。足すまで頭の `mock:` は赤。足すときは、下絵の `FreeDoc`・`Checks`・`BillTable`・`Img` を 1 枚に並べるだけで、新しい見た目は作らない
- **`DocView`（`doc-view.tsx`）は編集の部品を import しない**（`@tiptap/*`・`prosemirror-*` を読まない。境界 B10 の外から読んではいけない物を、この葉は触らない）。`@kaname/contracts` の `Doc` の型と定数だけを使う。サーバーでも描ける（`"use client"` を付けない）
- **利用者が選んだ `#rrggbb` の色の当て方（PM の決め 2026-11-23・案 2）**：JSX の `style={…}` でも `<style>` の要素でも当てない（class_gate・D8・K261-RL-017 を緩めない・例外も足さない）。文書に、形を確かめた `#rrggbb` の色（文字の色か背景）が **1 つでも在るときだけ**、読むだけの編集の部品（Tiptap・`editable: false`・K-567 の `buildExtensions()`）で描く。読み込みは遅い読み込み（`doc-view-color.tsx` が `doc-view-live.tsx` を動的に import する）で、読み込みの間は色を付けない読む形（`DocView` の描き）を先に出す。色の印（inline の style）は Tiptap が自分で付ける。**色の無い文書（大半）は編集の部品を読まないまま**（K577-UI-001）
- **色のある文書でも同じ結果にする物**：チェックの箱（取り扱いが無ければ disabled・在れば `onToggleTask(位置, 押した後の真偽)` を呼び、表示は渡された `doc` のまま＝Tiptap の `onReadOnlyChecked` で偽を返して戻す）／値の守り（Tiptap に渡す前に、K-567 の `fromEditorJson` で形に合わない色・寄せ・`colspan`・`rowspan`・`start`・許されない href を落とす）／前の 3 つの名前の色は `span[data-c]`（正本のトークン）／箱の名前（読み上げ）は箱の文／画像の置き場は `DocView` と同じ形（`figure.k-f4d-img`・枠は `role="img"`・名前＝caption・K577-UI-011）／表のセルの `colwidth` は読むだけの形でも使わない（渡す前に外す）。書き換えはできない（`contenteditable="false"`・入力欄の役を付けない）。見た目は `editor.css` のトークンでそろえる（K-567 の `k-f4d-pm` の決まりを読む形にも当てる）
- **描き**：K-561 の節ごとに、下絵 `features/F4/doc/views.tsx` の `FreeDoc`・`Checks`・`BillTable`・`Img` と同じ見た目（`doc.css` の `k-f4d-*`）。見出し（2・3）は `h2`・`h3`・段落は `p`・箇条書きは `ul>li`・チェックの箱は `ul.k-f4d-checks>li>input[type=checkbox]＋span`（済みは `data-done`）・表は `div.k-f4d-tablewrap>table`（1 行目が `th`）・引用は `blockquote.k-f4d-quote`・コードは `pre>code`・画像の置き場は `figure.k-f4d-img`（枠は `role="img"`・名前＝caption・押せない・D-150.57）・hardBreak は `br`。印は bold＝`b`・italic＝`i`・highlight＝`mark`・color＝`span[data-c]`（red・teal・amber）・link＝`a`。薄い字（`ghost`）は `k-f4d-ghost`／`k-f4d-ghost-h` の薄い見た目
- **リンクの守り**：許された href（`isAllowedHref`・K-567 の `link-policy.ts`）のときだけ `a`（`target="_blank"`・`rel="noopener noreferrer"`）。**許されない href は `a` にせず字だけ出す**（文書がサーバーに前から入っていた物でも守る）。`dangerouslySetInnerHTML` を使わない
- **チェックの箱**：`onToggleTask` を渡されないときは `disabled`（読むだけ）。渡されたときは押せて、`onToggleTask(index, checked)`（`index` は文書の中の taskItem の出てくる順の位置・0 から・入れ子も数える／`checked` は押した後の真偽）を呼ぶ。**部品の中で文書を書き換えない**（表示は渡された `doc` のまま。使う側が口で書いて新しい `doc` を渡す）。名前（読み上げ）は箱の文
- **遅い読み込みの確かめ**：開発用の頁を読む形で開いたとき、どの script にも編集の部品が入っていない。編集に切り替えると編集の部品が読まれる（K-567 の `DocEditor` が動的に読む）。確かめは試験の中の script の中身（`prosemirror-state`・`prosemirror-view`・`prosemirror-model`・`@tiptap/core`）で見る
- **画面の文**：読む形に字を足さない（下絵の字だけ）。開発用の頁のボタンの字『編集に切り替える』『読む形に切り替える』『箱を押せる読む形にする』『危ない href の文書にする』『広い表と長い字の文書にする』は開発用で、本番には出ない
- **足した節と印の描き**（代表の決め 2026-11-22・D-150.61「出来合いの編集の部品が持つ機能を絞らずに使う」。文書の木は K-584 が広げた形）：番号つきの並び＝`ol>li`（`start` が在れば `ol` の `start` 属性）・区切りの線＝`hr`・見出し level 2・3・4＝`h2`・`h3`・`h4`・文字の寄せ（段落と見出しの `textAlign`）＝4 つの値だけ（`DocView` の自前の描きは `data-align` と `editor.css`・読むだけの編集の部品は Tiptap が付ける inline の text-align。どちらも計算された text-align で確かめる）・表のセル＝`td`／`th` に `colSpan`・`rowSpan`（`colwidth` は読む形では使わない：結合したセルの幅を固定すると狭い幅で溢れるため。表は `k-f4d-tablewrap` の中で横に流れる）・見出しのセル `tableHeader` は行・列・セルのどこでも `th`・印は 下線＝`u`・取り消し線＝`s`・行の中のコード＝`code`・上付き＝`sup`・下付き＝`sub`・文字の色＝前の 3 つの名前は `span[data-c]`（正本のトークン）、`#rrggbb` は読むだけの編集の部品が付ける色（上の決め。`DocView` の自前の描きでは色を付けずに字だけ）・背景の色＝`mark`（属性の無い物は前のまま正本の黄、`#rrggbb` は同じく読むだけの編集の部品が付ける）。`ol`・`h4`・`hr`・行の中の `code` の見た目は `editor.css` に足す（既存の `--k-*` のトークンだけ・生の長さや色を書かない。無い物は K-431 の台帳に足してもらうと報告に書く）。下絵（mock）は触らない＝正の絵の組は `f4v2-body-read` のまま、足した分は開発用の頁の確かめ（行の役・字・計算された style）で見る
- **色の値の守り**：`color`・`highlight` の色は K-584 の形（前の 3 つの名前〔文字の色だけ〕か `^#[0-9a-f]{6}$`）に完全一致したときだけ色にする（名前は `data-c`・`#rrggbb` は読むだけの編集の部品へ渡す）。**形に合わない値は、サーバーに前から入っていた物でも、色を付けずに字だけ出す**（`rgb()`・名前・`url()`・大文字・3 桁・空・文字以外）。値を連結して style の文字列を作らない（決まった形の値だけを入れる）。`dangerouslySetInnerHTML` を使わない
- **口は呼ばない**
