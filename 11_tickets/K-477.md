## 目的

グループを選んだときの「概要」タブが開いたときに呼ぶ契約の口 `getScopeOverview`（GET /api/v1/scopes/:id/overview・今は 501）を作る。答えは契約どおり 4 つの鍵（D-128.10・範囲 P5）。

- `by_stage`：状態の内訳（会社の状態を位置の順に全部・0 件の状態も出す）。画面は 1 本の棒と件数にする
- `milestones`：節目の進み。節目の開始日・終わりの日を持つ列がまだ無い（`class_values` に列が無い・D-125.64）ので、**いつも空の並び**（画面は空の枠のグレー・D-145.9・D-151.10）

- `total`：そのグループとその下のグループのチケットの数
- 絵の「残りの量」「分類ごと」は契約にも決定にも無いので作らない（画面が空の枠のグレーで置く）。分析の固定画面は作らない（D-007）

## 前提と制約

分類: LIST, PERM

- 素の読み書きでは作れない（答えが 1 つの表の行でなく、状態ごとの数・チケットごとにまとめた最近のやり取りを組む）。hooks で作る。表も行の守りも変えない（読むだけ）
- 見える範囲は 2 段：①そのグループが呼んだ人に見えるか。見えるとは、`scopes` の行が同じ会社・消していない・`visible_scopes(自分)`（席のグループとその下・view か edit の権限が付いたグループとその下）に入ること。入らなければ 404（存在を教えない・件数も返さない）。**code は 2 通り**：入口の行の確かめ（`perm.row`・表 scopes・式 true・op.ts 266）が先に、無い uuid・別の会社の人・別の会社のグループ（行の守りで見えない・無い）を code `NOT_FOUND` の 404 にして口まで来ない。口が返せるのは、行の守りでは見えるが席の木の外のグループ・消したグループの 2 通りで、code は E-PAGE-001。口の中でも同じ確かめを持つ（消したグループ・席の木の外は入口を通るので、口の確かめが決め手）。画面（K-480）は code でなく状態コード 404 で出し分ければ足りる②数える・並べるのは、見えるグループとその下のグループ（`scopes.parent_id` をたどる）の、見えるチケット（行の守り `tickets_read` の上）で、消していない（`deleted_at`）・他の人の取り込みの下書きでない（`app.ticket_draft_ok`）物。口の文でも同じ条件を書く（2 重・K-92 と同じ）
- 内訳 `by_stage`：`ticket_stages` の、同じ会社・消していない状態を `position`・`name`・`id` の順に全部。1 件は `{ stage: { id, key, name }, count }`（key は会社が足した状態では null）。数は上のチケットの `stage_id` ごと。0 件の状態も出す。`total` は数の合計（完了の状態も数える）
- 最近の更新 `recent`：上のチケットについて、`ticket_messages`（書き込み・変更の 1 行・仕組みの 1 行の全部）のうち、消していない物で、**直近 14 日**（`created_at >= now() - interval '14 days'`）の物を、チケットごとにいちばん新しい 1 行にまとめ、新しい順（同じ時刻はチケット id の順）に **10 件まで**。1 件は `{ ticket: { id, number, title }, at, by: { id, display_name } | null, kind, text, count }`：`at` はその 1 行の時刻（ISO）・`by` は書いた人（仕組みの 1 行は null）・`kind` は post・change・system のまま・`text` はその 1 行の本文の先頭 80 文字（81 文字以上は 80 文字＋「…」・文字の数で数える・本文が無い（null）ときは空の字）・`count` は 14 日の中の、そのチケットのやり取りの数。14 日と 10 件は仮の数字（PM の決めとして報告する）
- 本文を 80 文字に切って出す訳：チケットを見られる人には、やり取りの本文も見えるので隠さない。長い本文を概要に全部出さないだけ
- 問い合わせは受けない（グループは道の値の id だけ）。知らない問い合わせは無視する（契約に問い合わせが無い GET）
- 1 つの取引（withTenant）の中で文は 3 つ以内（見えるグループの確かめ・内訳・最近の更新）。合計は内訳の数を足して作る（文を増やさない）。ログに題名・本文・番号を出さない
- 書かない・知らせない・証跡を残さない（読むだけの口。関門 C2 は読みの接続を通るだけ）
- 守りの判定（見えるグループ）の所で DB が落ちたら、口は例外のまま 500（onError・読むだけなので何も残らない）
- 画面の数の札・左のメニューの件数（getShell）とは別。この口は概要のタブを開いたときだけ呼ぶ
- 期限間近・詰まりの数は出さない（日数の設定が F9 で無い・D-145.9）。節目は 0 件。星付きグループは作らない
