## 目的

ナレッジのページの「必ず守る」を、書ける人が付け外しできるようにする（行為 A114・決め 4・10）。上限に届いたときは小窓で今付いているページを見せ、「外す」を押すとそのページを外して**続けてこのページに付ける**。あわせて、K-683 が置いた「書き終えるの前の差し込み口」（`publish-gate.tsx`）の中身を、**似たページを探して小窓で見せる**物に替える。似たページの小窓は上げる前（K-692）も使うので、探す部分は `similar-check.tsx` に分けて置く。

口は K-685（`setKnowledgeMust`・200 `{ id, must, used, limit }`・409 E-KNW-060 の体の `detail` に今付いている一覧）と K-686（`findSimilarKnowledge`・200 `{ pages: [{ id, title, desc, place }] }`）。K-682 の差し込み口 `page-slots.ts` に **1 行**足して入る。

- **付ける・外す**：つまみ「必ず守る」を押すと `setKnowledgeMust`（`PUT /knowledge_pages/:id/must`）を 1 回（体は `{ must }` だけ・冪等の鍵あり）。成功したらページと木を読み直し（`ctx.reload({ page, tree })`）、お知らせ（`useNotify`）「「必ず守る」を付けました（<棚>の棚 <used> / <limit> 件）」／「…を外しました（…）」（**仮**・`mustToast`・棚は `place.shelf_name`）。押し込みは読み直した `must` で決まる（口の答えを待つ間は動かさない）。答えを待つ間は押せない（二度押しでも口 1 回）
- **付けられない訳（本文が 2,000 字を超える・`must_blocked: "too_long"`）**：口は `must-on` を返すので、画面が**押せない形**（`aria-disabled="true"`・押しても口 0 回）にし、訳の文「本文が 2,000 字を超えているので、「必ず守る」は付けられません。」（**仮**）をページの頭の下に 1 行（`.k-f9-note`）出す。部品の `PageView` に任意の `mustBlocked?: string`（その文）を足す。口が先に 409 E-KNW-061 を返したとき（直前に長くされた）は下の失敗の出し方どおり
- **上限に届いた（口が 409 E-KNW-060）**：`mustFullOf(body)`（K691-UN-003）で体の `detail`＝`{ shelf_name, limit, pages: [{ id, title, folder }] }` を読み、部品の小窓 `MustFullDialog`（K-671）を出す：対象＝`pageTarget(place, title)`（「会社 › 経理 › 経費の精算」・グループの棚は「グループ：営業 › …」・K691-UN-002）・見出しの下の注意「<棚>の「必ず守る」は <limit> 個までです」・今付いているページ（`count` は一覧の数）・ページはそのまま（付かない・読み直さない）。形が違う体（`detail` が壊れている）は上限の小窓にせず、お知らせ（失敗）に E-KNW-060 の正本の文
- **小窓の「外す」**（部品に任意の `onRemove(id)` を足す）：押した行のページに `setKnowledgeMust`（`must=false`）→ 成功したら**続けて今のページに `must=true`**（外す口と付ける口の 2 本の順。最初の付ける口〔409〕を含めると 3 本）。2 本とも通れば小窓を閉じ、ページと木を読み直し、お知らせ「「必ず守る」を付けました（…）」。外す口が断った（409 E-KNW-011〔承認待ち〕・404・403・503・網の切れ）ら**小窓の中の赤い箱**（`NoticeBox`）に正本の文・一覧はそのまま・続けて付ける口は呼ばない。外せたあとの付ける口が断ったら、外したページを一覧から落とし、**また 409 E-KNW-060 なら一覧を新しい物に替える**（小窓は開いたまま）・それ以外は赤い箱。答えを待つ間は「外す」をどれも押せない（口はそれぞれ 1 回）
- **付ける口が上限以外で断った**（403・404・503・網の切れ・409 E-KNW-010・011・061）：お知らせ（失敗・自分で閉じるまで残る）に正本の文（`errorText` の最初の 1 文・つながらない〔`call` が投げる〕は E-PAGE-008）。押し込みは変えず、押し直せる。**404・409 は読み直す**（ページの今の形に合わせる）・403・503・網の切れは読み直さない
- **上限の小窓の閉じ方**：「閉じる」・Esc・右上の×は口を呼ばず閉じ、焦点は「必ず守る」に戻る
- **似たページ（`similar-check.tsx`）**：`useSimilarCheck(): { check(input): Promise<boolean>; dialog: ReactNode; open: boolean }`。`input`＝`{ page_id, title, desc, text, when: "save" | "raise", target }`。`check` は `findSimilarKnowledge`（`POST /knowledge/similar`）を 1 回（体は `similarBody`：題名は前後の空白〔全角も〕を落とす・説明は空なら送らない・本文は**頭の 500 字**〔コードポイントで数える〕・空なら送らない・`exclude_page_id` ＝ そのページ自身・K691-UN-004）。**空なら小窓を出さず `true`**。1 件以上なら小窓 `SimilarDialog`（K-671・題「似たページがあります」・一覧は題名・場所・説明・「開く」）を出し、「戻って直す」・Esc・右上の×で `false`・「このまま作る」（`when` が `raise` なら「このまま頼む」）で `true` を返す。**探す口が失敗したら（503・429・つながらない・どれでも）止めず `true`** を返し、お知らせ「似たページを探せませんでした。このまま書き終えます。」（`when` が `raise` なら「…このまま頼みます。」・**仮**）を出す（探すのは気づかせるだけで、書き終えるを止める理由にならない）。`open` は小窓が出ている間 true（K-692 が自分の小窓を隠すために使う）
- **「開く」**：新しいタブで `/knowledge/<そのページの id>`（`window.open(href, "_blank", "noopener")`）。小窓と書いている画面は残る（書いた字も残る）
- **`publish-gate.tsx`**（K-683 が置いた差し込み口・名前と型は変えない）：`usePublishGate()` は `useSimilarCheck()` を使い、`check(input)` で `when: "save"`・`target` は読み込み済みのページ（`useQueryClient` の `["k682","knowledge","page",page_id]`）から `pageTarget`（無ければ題名だけ）にして呼ぶ。`dialog` を返す。**K-683 の試験（K683-UI-011）は名前（`export function usePublishGate`）と「公開の口を呼ぶ前に `check` を呼ぶ」順だけを見る（中身の字は見ない・切る段で直した）ので、この葉が中身を書き替えても赤にならない。名前と順は変えない**。入れ物が外れた（画面を離れた）とき、待っている `check` は `false` で終える
