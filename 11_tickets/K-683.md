## 目的

ナレッジのページを書けるようにする（行為 A114・代表の決め 1・4）。読む形の「直す」を押すと、題名・1 行の説明・本文（段 5 の `DocEditor`・見たまま編集）の書いている画面になり、打つと**打ち終えてから約 0.8 秒後に下書きとして口に保存**され（印「自動で保存しました（HH:MM）」）、「書き終える」で公開（版が 1 つ進む）、「やめる」で下書きを捨てる。まだ 1 度も書き終えていないページは、やめるとページごと消える。「必ず守る」のページは本文が 2,000 字までで、超えると書き終えられない（字の数え方は口の答え）。

- 正の絵は下絵 v2 の `kn-write`（部品 `features/F9/knowledge/page-views.tsx` の `PageEdit`）。字は下絵が正。**下絵に無い字は仮**（下の「前提と制約」）
- 書き終える前の「似たページ」の小窓は K-691 の物。この葉は**差し込み口**（`publish-gate.tsx`）だけ置く
- 木の「＋」でページを足す・「…」の前の版・動かす・消すは K-684

## 前提と制約

分類: CRUD, PERM, XSS

- **代表に確認中・勧めで切る**（下絵に無い字は仮・下の「代表に聞くこと」）
- **入口**：K-682 の `WritingSlot`（`writing-slot.tsx`）の中身をこの葉が書き替える（名前と props は変えない）。`WritingSlot({ page, editing, setEditing, children })` は、**書いている画面にする**条件が真のとき `WritingPage` を、偽のとき `children`（読む形）を返す。条件は `editing`（いま「直す」を押した）か、口の答えの `page.state === "draft"`（まだ 1 度も書き終えていない）か、`page.draft` が在る（書きかけが口に在る）。**URL に持たない**（K-682 の決め）。`page-slots.ts` に `useWriteSlot`（`acts.edit = () => setEditing(true)`）を 1 行足す
- **書き始める**：「直す」を押しただけでは**口を呼ばない**（下書きは最初の保存で口ができる）。欄の初めの値＝`draft.title ?? page.title`・`draft.desc ?? page.desc`・本文＝`draft.doc ?? body.doc ?? 空の木`。開いたとき本文に焦点が行く。口の答え `getKnowledgePage.draft` は K-677 が `{ title, desc, doc, saved_at }` で返す（書きかけの題名と説明を再読み込みで失わない）
- **自動で保存する**（`use-page-writing.ts`）：定数 `AUTOSAVE_MS = 800`（打ち終えてからの間）。題名・説明・本文のどれを打っても、最後に打ってから 800 ms 後に **1 回にまとめて** `saveKnowledgeDraft`（`PATCH /knowledge_pages/:id/draft`）を呼ぶ。**体は前の保存から変わった欄だけ**（`title`・`desc`・`doc`。`text` は送らない・口が `doc` から作る）。題名が空白だけのときは `title` を送らない。答えを待つ間にまた打ったら、答えのあとに続きを 1 回送る（同時に 2 つ飛ばさない）。保存の口の呼び方は 120 回／分（K-679 の決め）に収まる
- **印**（`PageEdit` の `saved`・`role="status"`）：保存の前は下書きの時刻（`draft.saved_at`）があれば「自動で保存しました（HH:MM）」・無ければ空／答えを待つ間「保存しています…」（**仮**）／通った後は答えの `saved_at` を日本時間 HH:MM に直して「自動で保存しました（HH:MM）」（下絵の字）／失敗（503・網の切れ・ほか）は「自動で保存できませんでした」（**仮**・`data-kind="failed"`）で、書いた字は残り**次に打つともう一度送る**。通れば印が戻る
- **別の人が下書き中**（保存の口が 409・E-KNW-012）：書いている画面の上に赤い箱（`NoticeBox`・正本の文）。書いた字は残る。**「書き終える」は押せない**（押せない形・`disabled`）。「やめる」は確かめの小窓の後、口を呼ばずに読む形へ（自分の下書きはまだ無いので捨てる口は 0 回）
- **書き終える**（`finish()`・順に）：①送っている間は二度目を送らない（ボタン `disabled`・`aria-busy`）②題名が空白だけなら口を呼ばず題名の欄の下に「題名を入れてください」（**仮**・`aria-invalid`・焦点を題名へ）③**公開済みで何も直していない**（口に下書きが無く、欄も開いたときのまま）なら口を呼ばず読む形へ ④送っていない直しがあれば先に保存して答えを待つ（失敗したら下の出し方で止まる）⑤`const ok = await gate.check({ page_id, title, desc, text })`（`usePublishGate()`・既定は `true`＝K-691 が似たページの小窓で「戻って直す」なら `false`）⑥`ok` なら `publishKnowledgePage`（`POST /knowledge_pages/:id/publish`・体は `{}`・冪等の鍵あり）⑦通ったら `reload({ page: true, tree: true })`（K-682 が決めた型 `reload(what?: { page?: boolean; tree?: boolean })`） して `setEditing(false)`、画面の下の小さなお知らせ（`useNotify`）「ページを書き終えました」（**仮**）
- **やめる**：公開済みで直していない（口に下書きも無い）なら確かめなしで読む形（口 0 回）。**直した／口に下書きがある公開済み**は小窓「書いた内容を捨てますか」（本文「やめると、いま書いている内容は消えます。」・ボタン「書き続ける」「捨てる」・`Dialog`）→「捨てる」で `discardKnowledgeDraft`（`DELETE …/draft`）1 回（口に下書きが無いときは 0 回）→ `reload` して読む形。**まだ書き終えていないページ**（`state === "draft"`）は小窓「このページを消しますか」（本文「まだ書き終えていないページは、やめるとページごと消えます。」・ボタン「書き続ける」「消す」）→ `discardKnowledgeDraft` が `page_deleted: true` を返したら `/knowledge` に移り木を読み直し、お知らせ「ページを消しました」（**仮**）。捨てる口が 409・E-KNW-030（もう無い）なら失敗にせず読み直して読む形へ。503 などは小窓の中の赤い箱（`role="alert"`）で、字は残り押し直せる
- **失敗の出し方**（書き終える）：409・E-KNW-041（必ず守るは 2,000 字まで）・409・E-KNW-040（書き終える下書きが無い）＝赤い箱に正本の文／401＝入り直しへ勝手に移さず（`keepOn401`）赤い帯（題「ログインが切れました」・要約「入り直すと、いま書いている内容は消えます。必要なら、先に別の場所へ写してください。」・ボタン「ログインし直す」＝`/login?next=<今の道>`）／403 → E-PAGE-002・404 → E-PAGE-001・503 → E-PAGE-003・つながらない → E-PAGE-008 を赤い箱（`errorCodeOf`）。どれも書いた字は残り、編集の形のまま、もう一度押せて、通れば赤い箱は消える。赤い箱は `role="alert"` を 1 つだけ
- **題名と説明の上限**：どちらも 200 字（欄の `maxLength`・口も 200 字を超えると 422）。本文の字の数は画面で数えない（口の答え）
- 画面は役の名前で出し分けず、口の答え（`acts`・断り）で出し分ける。本文は字として描く（`dangerouslySetInnerHTML` を使わない）。編集の部品の中身（Tiptap の型）を import しない（`features/F4/doc/editor` の `DocEditor` だけ・K-567 の境界）
- **書いている最中に離れる**（決め：移るのを止めず、送りきる）：送っていない直し（最後に打ってから 800 ms 経っていない分・保存中の分）があるまま、木で別のページを押す・戻る・進むで道が変わったら、入れ物が移った後に、元のページの id へその直しを 1 回送りきる（`use-page-writing.ts` の後始末・体は変わった欄だけ）。移った先は読む形で開く（K-682 の `editingAfterNavigation` が `editing` を戻す）。送りが失敗しても移った先は止めない（失敗は元のページを開き直したとき口の下書きが古いだけ）。再読み込み・タブを閉じるときは、送っていない直しがあるときだけ `beforeunload` の確かめを出す（保存し終えたら出さない）
- **読み上げ・キーボード**：「直す」は button・題名と説明は textbox・本文は textbox「本文」・印は `role="status"`・赤い箱と帯は `role="alert"`。Tab の順は 題名 → 説明 → 本文の道具 → 本文 → やめる → 書き終える
