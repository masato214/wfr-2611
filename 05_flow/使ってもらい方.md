```
A01 アカウントを作る（会社名が空なら本人の名前で個人のテナント）

 → A101 チケットの中身（区画）を書く・直す
 → A102 テスト仕様を作る（AI の案・抜けの点検・種類と型を確かめる）
 → A104 AI に任せる
 → A15 承認する／自分で直す／差し戻す／止める
 → A53 分身がやったことを見る → チケットへ戻る

```
