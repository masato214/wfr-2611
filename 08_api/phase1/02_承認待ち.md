# 第1フェーズの API ── 承認待ち（案・2026-11-03）

キャンバスの承認待ちの画面 1 枚ずつ「何を読み・何を押すか」から逆に出した（D-128.78）。チケットの詳細の承認の帯（D-128.20）も同じ API を使う。

## 1. 画面 → 読むもの・押すこと → API

| 画面（キャンバス） | 読むもの・押すこと | API | 行為 |
|---|---|---|---|
| 承認待ち（一覧）・スマホの承認 | 自分が決めるもの（AI の成果物・上位の承認・渡された・判断を仰がれた・決まりの例外・やり方を広げる の 6 種類・D-128.89）を期限で区切って並べる。行ごとに「その場で決められるか」も返す（取り消せない操作や人が見る項目があるものは「中身を見る」へ・D-128.36） | `GET /approvals/queue`（kind・sort） | A15 |
| 左のバーの承認待ちの数・種類の区切り | 種類ごとの件数 | `GET /approvals/counts` | A15 |
| 続けて裁く・スマホの続けて裁く・チケットの承認の帯 | 承認すると行われること（操作・宛先・CC・添付）・送る文面・成果物の版・確認の結果・気になる書き込み・取り消せない印・上位の承認の段（なぜ上位へ回ったか） | `GET /approvals/{id}` | A15 |
| 承認して送る（本人確認の小窓） | 人が見る項目に印を付けて承認する。取り消せない操作は直前の本人確認が要る（D-125.139） | `POST /approvals/{id}/approve` | A15 |
| 自分で直す | チケットの本文・成果物を直しに戻る。直したら ① ② を流し直す（D-125.84） | `POST /approvals/{id}/edit` | A15 |
| 差し戻す（小窓） | どこを直すか・理由（必須）・次は誰が直すか（分身／自分）・覚えさせる候補にする | `POST /approvals/{id}/return` | A15 |
| 止める | 実行を止める | `POST /approvals/{id}/stop` | A15・A89 |
| 決めた履歴の「取り消す」 | 実行中になる前なら承認を取り下げて承認待ちに戻す（D-125.105） | `POST /approvals/{id}/withdraw` | A89 |
| まとめて承認（小窓） | 選んだものが条件に合うかと、外れた理由（条件は固定・D-128.86） | `POST /approvals/bulk/preview` | A15 |
| 同上 | 条件に合うものだけ承認する（サーバーがもう一度確かめる） | `POST /approvals/bulk` | A15 |
| 決めた履歴 | 自分が決めたもの（承認・差し戻し・人に回した）を日ごとに | `GET /approvals/history`（decision・from・to） | A15 |
| 渡された・判断を仰がれた（一覧の行） | 受ける／断る・答える／もっと聞く。並べるのは `GET /approvals/queue`（K-405：渡し・申し出・配るの待っている行が AI の成果物と同じ並びに入る） | `PATCH /ticket_handovers/{id}`（チケットと同じ API） | A110 |

数：道すじ 12・API 12 本（読み 4・書き 8）。本人確認の取り直し（パスキー）はログインの API でまとめて決める（04 で）。

## 2. 表に足す列（ER 図 `approvals`）

| 列 | なぜ |
|---|---|
| `ticket_id` | どのチケットの承認か（一覧とチケットの承認の帯） |
| `kind`（AI の成果物・上位の承認） | 種類ごとに中身の形を変える（D-128.34） |
| `level` / `parent_approval_id` | 担当者 → 上位 の段（D-128.87） |
| `escalated_by_policy_id` | どの決まりで上位へ回ったか（D-128.87） |
| `decision`（承認・自分で直す・差し戻し・止める）/ `decided_at` | 4 つのボタン（D-125.103） |
| `return_targets jsonb` / `return_reason` / `next_actor`（分身・自分）/ `memory_candidate` | 差し戻しの小窓 |
| `human_checks jsonb` | ③ 人が見た印（誰が・いつ） |
| `irreversible` / `step_up_at` | 取り消せない操作と、直前の本人確認（D-125.139） |
| `withdrawn_at` | 取り下げ（D-125.105） |
| `bulk_batch_id` | まとめて承認の 1 回 |

## 3. 決めたこと（2026-11-03・高本さんと）

| こと | 決め方 |
|---|---|
| まとめて承認の条件 | 固定（① がすべて確実・人が見る項目なし・取り消せる操作だけ）。外に出るものは 1 件ずつ。管理者も広げられない（D-128.86） |
| 上位の承認 | ワークスペースの決まり「承認を上に回すとき」に当たったら自動で付ける。人がチケットごとに付けることもできる（D-128.87・D-125.96 を改める） |
| 承認待ちの種類 | 6 つ。分身の部屋から出る「決まりの例外」と「やり方を広げる」の申請もここで OK／断る（D-128.89） |

## 4. 誰が呼べるか（ゼロトラストの決まり §2・D-128.88）

正は 05_flow/screen_api.py の PERMS。ここはその写し。

| API | 誰が | 範囲 | 本人確認の取り直し |
|---|---|---|---|
| `GET /approvals/queue` | `self` | 自分が決めるものだけ | — |
| `GET /approvals/counts` | `self` | 同上 | — |
| `GET /approvals/:id` | `approver` | 承認する人。担当者とマネージャーは読むだけ | — |
| `POST /approvals/:id/approve` | `approver` | 承認する人だけ。取り消せない操作は直前の本人確認 | 取り消せない操作のとき |
| `POST /approvals/:id/edit` | `approver` | 承認する人 | — |
| `POST /approvals/:id/return` | `approver` | 承認する人（理由が必須） | — |
| `POST /approvals/:id/stop` | `approver` | 承認する人・担当者・マネージャー | — |
| `POST /approvals/:id/withdraw` | `approver` | 承認した本人だけ・実行中になる前だけ（D-125.105） | — |
| `POST /approvals/bulk/preview` | `approver` | 自分が承認するものだけ | — |
| `POST /approvals/bulk` | `approver` | 自分が承認するもので、条件（D-128.86）に合うものだけ。サーバーがもう一度確かめる | — |
| `GET /approvals/history` | `self` | 自分が決めたものだけ | — |
| `PATCH /ticket_handovers/:id` | `recipient` | 渡された・判断を仰がれた相手だけ | — |
