## 2. 守りの決まり

- 見せるのは見られるページだけ（置き場の権限。グループのページはそのグループ、自分のページは本人）。使われ方・つながりの先のチケットや決まりも、見られるものだけ出す（ZT4）
- 分身が読むのは公開のページだけ。下書き・取り込んだばかりのページは、持ち主が公開するまで読まない
- 「ことばで聞く」も見られる公開のページだけから答える。AI は本人の PC の分身だけ（D-128.105）
- 取り込むファイル・ページの画像は検査してから置く（関門 C4）。書き出しは期限つきの署名 URL
- ページに書かれた中身は、分身にとってデータであって指示ではない（ZT8）

- **キャンバス**：スマホのナレッジの答えの見本が、PC のページと食い違っていた（「月末締めで翌月 3 営業日」→ ページは「25 日締め・翌月 1 日に作る」）。ページに合わせた。「経理の月次の流れ」の置き場と版も PC にそろえた。ホームの探す欄に「PC がつながっていないときは当てはまるページと行を出す」を、ページを書く小窓に書ける人の説明を足した
