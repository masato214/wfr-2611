## 2. 守りの決まり

- 運営の API は運営の人で、そのできることを持つ人だけ。数と種類だけの画面（一覧・1 社のいまの状態・記録）は `ops:any`（運営の人なら誰でも）
- 中を見る・止める・再開する・入金を記録する・請求書をまとめて出す・代わりにプランを変える・運営の人を足す／変える／外す は本人確認を取り直す（ZT5）
- 中を見るは理由が必須・1 時間・見るだけ。預けたログイン情報の値は運営にも見えない（D-128.68）
- **運営がしたことは、運営の記録と顧客の記録の両方に残る**（ZT12・D-128.108）
- 一覧と 1 社の画面に中身（チケット・会話）は出さない。問い合わせに付いてくるのは画面の場所・時刻・ブラウザ・PC のつながりだけ
- 自分のできることは変えられない・自分は外せない。値段の案と値段を決めるは分ける
- ログインの前に読めるのは稼働状況とメンテの予定だけ（どのワークスペースのことも出さない）
